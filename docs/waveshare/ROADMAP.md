# Waveshare RID-01 — final roadmap disposition

**Superseded November 17, 2026:** The original pre-GNSS roadmap described LC76G integration and eventual Wi-Fi/microSD development. GNSS was implemented and tested through R7; subsequent microSD and Wi-Fi work were **not** performed on this board. Project development has concluded following unacceptable operator-observed outdoor field reliability.

See the [final assessment](R7_FINAL_ASSESSMENT.md), [R7 technical validation](R7_VALIDATION.md), [final source](../../firmware/waveshare/final-r7/RID_UI_Migration/RID_UI_Migration.ino) and [portfolio case study](R7_CASE_STUDY.md).

Prior roadmap text and acceptance boundaries are preserved in Git history for provenance. **This document is the controlling current plan: no further Waveshare firmware work planned.**
